```
S[φ + εδφ] = ∑ (Δ(φ+εδφ))²/2
            = ∑ (Δφ + εΔ(δφ))²/2
            = ∑ (Δφ)²/2 + ε·∑ Δφ·Δ(δφ) + ε²·∑ (Δ(δφ))²/2
            = S[φ] + ε·δS[φ,δφ] + O(ε²)
```

**关键引理**（离散分部求和 / Abel 求和）：
```
∑_x Δφ(x)·Δ(δφ)(x) = -∑_x δφ(x)·Δ²φ(x) + 边界项
                    = -∑_x δφ(x)·Δ²φ(x)  (变分在边界为 0)
```

因此驻点条件 `δS = 0` ⟺ `Δ²φ = 0`（离散 Laplace 方程）。

**Lean 工具**：
- `Finset.sum_mul` + `Finset.sum_comm`
