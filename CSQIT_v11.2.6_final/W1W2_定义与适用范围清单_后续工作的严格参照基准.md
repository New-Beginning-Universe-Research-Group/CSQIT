### 问题 1：AxiomB' 的描述（§1.1）

**清单**：
```

```

**实际代码**（Axioms.lean:447-470）：
```lean
class AxiomB' (M C : Type*) [A' : AxiomA' M C] where
  le : M → M → Prop
  lt : M → M → Prop
  ...
  weaving_axiom' : ∀ (α : C) (x : M), x ∈ A'.input α → lt x (A'.output α)
```

**修正**：AxiomB' 与 AxiomB 的唯一区别是 `weaving_axiom'` 使用 `A'.input`/`A'.output`。`le_total` 在 `AxiomB_totalOrder` 和 `AxiomB'_totalOrder` 中。
