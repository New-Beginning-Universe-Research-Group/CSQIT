### 0.2 W1 层：时间 = 因果序（严格定义）

**定义来源**: `CausalLattice M` 的偏序关系 `≤`

**核心要素**:
1. **时间箭头**: 由偏序的方向性给出（`x ≤ y` 表示 x 在因果上先于 y）
2. **离散性**: 通过 `isImmediateSuccessor` 实现——时间的流逝是离散的"下一刻"跳跃
3. **起点与终点**: `BoundedCausalLattice` 的 `⊥`（大爆炸）和 `⊤`（最终状态）
4. **时间非交换性**: 顺序复合 `seq` 非交换 → 时空分化的前提（[WeavingStructure.lean](file:///d:/CSQIT-workspace/CSQIT_v11.2.6_final/Core/W1/WeavingStructure.lean)）

**关键定理支撑**:
- `sup_monotone`: 因果并集保持时间序（更晚事件的并集也更晚）
- `bot_unique` / `top_unique`: 时间起点和终点的唯一性

### 0.3 W2 层：时间 = 尺度流（精细化过程）

**定义来源**: `projectiveScale n = 2π · n / (n+1)`

**核心要素**:
1. **尺度参数 n**: 自然数索引，对应因果格的精细化程度（宇宙的"发育阶段"）
2. **单调递增**: `projectiveScale_strictMono`——尺度随 n 严格递增，时间不可逆
3. **有限到无限的过渡**: `projectiveScale n < 2π` 对所有有限 n 成立，但 n→∞ 时趋近 2π
4. **离散时间导数**: `d_dt O n dt = (O(n+1) - O(n)) / dt`——时间变化率从尺度差分导出

**物理意义**:
- 人类感知的"时间流逝" = 因果格的精细化过程
- "无限远的未来"在拓扑圆上闭合（走完一圈回到起点）
- 物理中处处有 π，因为尺度流在拓扑圆上闭合

### 0.4 W3 层：时间 = 发展过程（生长/演化）

**定义来源**: 生长脉络与对称谱系的逐级涌现

**核心要素**:
1. **生长层级**: 三群谱系 = 三个生长阶段（A₄ → A₅ → PSL(2,7)）
2. **不可逆性门槛**: d ≥ 3（p=7）时动力学不可逆，时间箭头真正出现（[Fin7Uniqueness.lean](file:///d:/CSQIT-workspace/CSQIT_v11.2.6_final/Core/W2/Fin7Uniqueness.lean)）
3. **大尺度循环**: 循环宇宙模型——局域时间有方向，全局时间闭合（[CyclicUniverse.lean](file:///d:/CSQIT-workspace/CSQIT_v11.2.6_final/Core/W3/CyclicUniverse.lean)）
4. **三锁常数**: 20, 111, 289 是三个生长阶段的贡献比例

### 0.5 全局一致性：时间的三位一体

```
W1: 因果序 ≤  ──┐
                 ├── 同一实在的三个侧面
W2: 尺度流 n   ──┤     （时间 = 序 = 尺度 = 发展）
                 │
W3: 生长过程   ──┘
```

**贯穿始终的数学线索**:
- **W1 → W2**: 因果格的精细化序列（`seq : ℕ → Type*`）将抽象因果序具体化为尺度参数
- **W2 → W3**: 尺度流驱动对称群逐级涌现，构成发展过程的"里程碑"
- **W3 → W1**: 生长的每个阶段都是一个因果格（满足 W1 公理），发展过程不违反因果序

**使用原则**:
1. 涉及严格因果结构时，使用 W1 层的 `CausalLattice` / `≤` 语言
2. 涉及连续极限、变化率时，使用 W2 层的 `projectiveScale` / `d_dt` 语言
3. 涉及宇宙演化、对称涌现时，使用 W3 层的生长脉络语言
4. 三层表述等价，选择取决于语境，**不得出现层级混淆**

### 0.6 与"4D时空"的关系

**关键澄清**: CSQIT 中的"4D" **不是** 平权的 4 个维度，而是：

> **3D 空间 + 时间流（因果演化）**

- 3D 空间 = 同一因果深度的空间截面（同时性切片）
- 时间流 = 截面之间的因果序关系（不是额外的空间维度）
- 4D 收敛性 = 每个 3D 切片各自的连续极限 + 切片间的望远镜消去

这与传统相对论将时间作为第四维度处理有本质区别：时间是更基本的因果序，空间从时间中涌现（`par ≠ seq` 时空间分化）。

### 1.8 标准公理 vs 增强公理：适用范围的根本差异 ⚠️

**核心结论：标准公理与增强公理（'版本）适用范围有巨大差异，不可混用。**

| 维度 | 标准公理 (AxiomA/B/C/D) | 增强公理 (AxiomA'/B'/C'/D') |
|------|------------------------|---------------------------|
| **output 行为** | `compose_output = output β`（只保留右参数，左参数信息丢失） | `compose_output' = combine (output α) (output β)`（保留双方信息） |
| **input 行为** | 受 `input_must_be_empty` 约束，`input α = []` 对所有 α | 同样受 `input_must_be_empty` 约束（因为 compose_input 形式相同）|
| **weaving_axiom** | 空洞成立（前提恒假） | 同样空洞成立（input 仍为空），但 output 非退化使因果序有真实对象 |
| **振幅乘法律** | `amplitude (A.compose α β) = amplitude α * amplitude β`，但因 output 退化，振幅与因果面解耦 | `amplitude (A'.compose α β) = amplitude α * amplitude β`，output 非退化，振幅与因果面可耦合 |
| **两面性定理** | 完整适用（`output_degenerate_theorem` 等） | 不适用（`compose_output'` 不满足 `output(compose α β) = output β`，左可迁前提改变） |
| **核心坍缩定理** | `input_must_be_empty` 适用 | `input_must_be_empty` 同样适用（input 侧结构不变） |
| **模型实例** | `trivialModel` (Unit), `boolModel` (Bool), `nonTrivialFinModel` (Fin 5/4) | `fin7Model` (Fin 7), `fin8Model` (Fin 8), `natPartialModel` (ℕ) |
| **适用场景** | 纯代数/纯因果面的严格定理证明 | 非平凡动力学、振幅-因果耦合、物理意义建模 |

**关键定理支撑**：
- `AxiomA_to_AxiomA'`：标准 AxiomA 可视为 AxiomA' 的退化特例（取 `combine _ b := b`）
- `output_degenerate_theorem`：在左可迁 + 标准 AxiomA 下，output 退化为常函数
- `two_aspects_are_decoupled`：标准公理下振幅面与因果面解耦（无函数依赖）

**使用原则**：
1. **严格定理证明**优先使用标准公理（假设最弱，结论最普适）
2. **非平凡模型构造**必须使用增强公理（否则 output 退化，物理意义空洞）
3. **不得将标准公理下的定理直接外推到增强公理**（如两面性二一定理在 AxiomA' 下不成立）
4. **增强公理下的定理需标注其前提**（明确依赖 AxiomA' 的 compose_output'）
