## 二、G1：`EffectiveFin7Regular` 实例化攻坚

### 2.1 问题描述

`EffectiveFin7Regular M` 定义为：
```lean
(internalAverageOutDegree M = k_out_Fin7) ∧
(twoAspectParameter M = k_in / (k_in + k_out))
```
其中：
- `k_out_Fin7 = 1 + cos(2π/7)` ≈ 1.6235
- `k_in = 1`
- `θ = k_in / (k_in + k_out)` ≈ 0.38197

**当前状态**：这是一个 `def`，从未被任何具体模型满足过。

### 2.2 攻坚路线

#### 阶段 1：在 Fin 7 模型上直接验证（最容易，优先做）

**目标定理**：
```lean
theorem fin7_satisfies_EffectiveFin7Regular :
    EffectiveFin7Regular (Fin 7) := by
  sorry
```

**策略**：
1. 计算 `fin7Model` 中的 `internalAverageOutDegree (Fin 7)`
2. 计算 `twoAspectParameter (Fin 7)`
3. 验证它们是否等于预期值
4. 如果不等，分析差异，调整模型或定义

**技术路径**：
- `internalAverageOutDegree` 基于 `Set.ncard` 和 `isImmediateSuccessor`
- 在 `Fin 7` 上，`isImmediateSuccessor` 有明确定义（由 `fin7AxiomB'` 给出）
- 理论上可以用 `decide` 或 `norm_num` 直接计算
- 但需要先把 `fin7Model` 的因果序结构展开

**风险点**：
- Fin 7 的标准因果序（模 7 加法）可能不满足 `EffectiveFin7Regular`
- 如果不满足，需要寻找：
  - 调整 `internalAverageOutDegree` 的定义？
  - 寻找更复杂的 Fin 7 因果格结构？
  - 接受 Fin 7 只是"近似"满足？

#### 阶段 2：如果 Fin 7 不满足，在更大的有限模型上寻找

**候选模型**：
- Fin 8
- Fin 21（3×7，三锁常数的数论暗示）
- Fin 42（2×3×7，三群阶的 lcm/2）

**策略**：
1. 写一个通用的有限模型验证工具
2. 系统搜索小阶数的因果格
3. 找到满足 `EffectiveFin7Regular` 的最小模型

#### 阶段 3：构造性证明——设计满足条件的模型

如果没有现成的模型满足，就主动构造一个：
1. 设计一个因果格，其内部平均出度精确等于 `k_out_Fin7`
2. 调整边界/体积比，使 `twoAspectParameter` 精确等于 θ
3. 这不再是"发现"，而是"构造"——但同样有价值

### 2.3 预期产出

| 产出 | 类型 | 价值 |
|------|------|------|
| `fin7_satisfies_EffectiveFin7Regular` 或其否定 | 定理 | 直接决定后续所有 θ 相关定理的地位 |
| 如果成立：批量升级 10+ 条件定理为非条件 | 定理升级 | W2 层整体坚实度大幅提升 |
| 如果不成立：修正模型或定义 | 理解深化 | 明确 Fin 7 与正则性的真实关系 |

## 三、G2：`h_decomp` 维度递归分解攻坚

### 3.1 问题描述

`h_decomp` 是 `reggeConverges4D_to_EinsteinHilbert` 定理的关键前提：
```lean
h_decomp : ∀ n, reggeAction3D_slice (tetrahedra_seq n) (angle_seq n) (volume_seq n) =
              (projectiveScale n / (2 * Real.pi)) * ((4 * Real.pi) / (k_out_Fin7 ^ 2))
```

它断言：3D 切片的 Regge 作用量 = 尺度因子 × 常数。

**当前状态**：作为 `sorry` 前提引入，证明直接代入后归结为 `n/(n+1) → 1` 的简单极限。

### 3.2 攻坚路线

#### 阶段 1：理解这个等式为什么应该成立（物理/几何直觉）

**核心思想**：维度递归
- 2D 情形：通过离散 Gauss-Bonnet 定理，Regge 作用量 = 2πχ（欧拉示性数），是拓扑不变量
- 3D 情形：3D 流形的标量曲率可以通过其 2D 截面的曲率平均得到
- 4D 情形：沿时间方向积分，加上类时项的望远镜消去

**需要形式化的步骤**：
1. 3D Regge 作用量的定义（已存在 `reggeAction3D_slice`）
2. 2D Gauss-Bonnet 定理（已存在，定理 8.4）
3. 维度递归公式：3D 曲率 = 2D 截面曲率的某种平均（待定义/证明）
4. 尺度与作用量的关系：为什么是 `projectiveScale n / (2π)`？

#### 阶段 2：从 2D Gauss-Bonnet 出发，建立 3D 版本

**目标**：证明 3D Regge 作用量也有类似的拓扑控制

**策略**：
1. 先在简单的 3D 复形上验证（如四面体边界、立方体）
2. 寻找 3D 情形下的"欧拉示性数"类比
3. 或者证明一个更弱的结论：比例关系，而非精确等式

#### 阶段 3：如果精确等式太难，证明渐近版本

**退而求其次**：
- 不证明对所有 n 精确相等
- 只证明：当 n→∞ 时，比例趋近于 1
- 这样 Regge 收敛定理仍然成立（极限相同）

**修改后的定理形态**：
```lean
theorem reggeConverges4D_asymptotic :
    Tendsto (fun n => reggeAction4D n) atTop (nhds ((4*π) / k_out_Fin7^2)) := by
  -- 证明比例 → 1，而不是比例 = 1
```

### 3.3 预期产出

| 产出 | 类型 | 价值 |
|------|------|------|
| 维度递归引理（2D→3D） | 新定理 | 连续极限理论的核心数学工具 |
| Regge 收敛定理升级（去 `sorry`） | 定理升级 | W2 层标志性成果 |
| 如果精确太难，至少证明渐近版本 | 弱化版定理 | 保持物理解释力，数学上更诚实 |

## 四、G3：Fin 7 唯一性的正向证明攻坚

### 4.1 问题描述

当前有：
- ✅ `prime_exclusion_theorem`：p ≠ 7 时，θ(p) ∉ (0.28, 0.33)（排除法）
- ✅ `p7_is_first_irreversible`：p = 7 是第一个不可逆素数
- ❌ 缺少：从第一原理（生长公理、因果格公理）导出"必须是 7"的正向论证

论文中提到的"3×3 仿射平面模 8 同余"等论证，在代码中完全缺失。

### 4.2 攻坚路线

#### 阶段 1：系统化整理已有的数论支撑

**已有的成果**：
1. 可逆性门槛：d ≥ 3 时不可逆（d = (p-1)/2）
2. 素数排除：只有 p = 7 让 θ 落入结构形成窗口
3. 代数次数：7 次分圆域的次数是 6，与三维空间的 6 个对称（旋转+反射）有对应关系？

**目标**：把这些零散结果编织成一个更连贯的叙事

#### 阶段 2：探索"为什么是 7"的代数结构解释

**几个可能的方向**：

**方向 A：PSL(2,7) 的独特性**
- PSL(2,7) 是阶数为 168 的单群
- 它是最小的非阿贝尔单群之一（仅次于 A5 的 60）
- 它作用于 Fano 平面（7 个点，7 条线）
- Fano 平面是最小的射影平面

**方向 B：7 是满足多个约束的最小素数**
- p ≥ 3（非平凡）
- p 是素数（域结构）
- d = (p-1)/2 ≥ 3（不可逆，时间箭头）
- θ(p) ∈ (0.28, 0.33)（结构形成窗口）
- 同时满足这些的最小 p 就是 7

**方向 C：生长理论的推导**
- 从生长公理出发，证明某种"最小不可逆结构"的阶数必为 7
- 这需要连接 W1 的生长理论与 W2 的数论分析

#### 阶段 3：形式化"最小满足约束的素数"定理

**目标定理**：
```lean
theorem seven_is_minimal_satisfying_all_constraints :
    ∀ p : ℕ, p.Prime → p ≥ 3 → 
    (isIrreversible p ∧ theta_in_structure_window p) → p ≥ 7 := by
  -- 证明 7 是同时满足不可逆和 θ 窗口的最小素数
```

这虽然还是"排除法"的变体，但它把"最小性"明确为定理，比零散的排除更有说服力。

### 4.3 预期产出

| 产出 | 类型 | 价值 |
|------|------|------|
| Fin 7 唯一性的系统化数论支撑 | 定理集合 | 强化"7 非后验选择"的论证 |
| `seven_is_minimal_...` 最小性定理 | 新定理 | 从"排除法"升级为"最小性原理" |
| 与生长理论的连接尝试 | 探索性 | 可能开辟 W1→W2 的新通道 |
