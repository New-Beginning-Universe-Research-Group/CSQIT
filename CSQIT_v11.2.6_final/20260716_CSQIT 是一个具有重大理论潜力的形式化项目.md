## 核心数学构造

### 1. 因果位点与因果序

```lean
structure CausalSite (M : Type*) where
  idx : ℕ
  out : M

def causalLT {M : Type*} (x y : CausalSite M) := x.idx < y.idx
def causalIncomparable {M : Type*} (x y : CausalSite M) :=
  x ≠ y ∧ ¬ causalLT x y ∧ ¬ causalLT y x
```

**物理解释**：`causalIncomparable` 的三分量结构（`x ≠ y ∧ ¬causalLT x y ∧ ¬causalLT y x`）显式排除自反情形，避免了 Eckmann-Hilton 论证导致的时空合一退化。

### 2. 编织路径与复合

```lean
structure Weave {M : Type*} (L R : CausalSite M) where
  path : List (CausalSite M)
  path_nonempty : path ≠ []
  head_eq : path.head path_nonempty = L
  last_eq : path.getLast path_nonempty = R
  causal_chain : ∀ (i : ℕ) (hi : i + 1 < path.length),
    causalLT (path[i]'(by omega)) (path[i + 1]'(by omega)) ∨
    causalIncomparable (path[i]'(by omega)) (path[i + 1]'(by omega))
```

**关键性质**：
- `seq`（顺序复合）= 时间，仅当端点匹配时可复合
- `par`（并行复合）= 空间，仅当位点不可比时可复合
- 两者都是部分定义的，Eckmann-Hilton 论证不适用

### 4. 射影尺度紧化

```lean
def projectiveScale (n : ℕ) : ℝ :=
  2 * Real.pi * (n : ℝ) / ((n : ℝ) + 1)
```

**物理解释**：当精细化程度 `n → ∞` 时，`projectiveScale(n) → 2π`，对应圆上走完一圈回到起点——这就是物理中处处有 π 的原因。

## 关键定理与猜想

### W1 级定理（已证明）

1. **因果格存在性定理**：在有限类型上存在满足四条核心公理的因果格结构。

2. **编织闭包定理**：编织路径的顺序复合和并行复合在因果不可比条件下封闭。

3. **Interchange 定理**：在四路径方块不可比条件下，`seqPar = parSeq`。

4. **三群谱系定理**：A₄、A₅、PSL(2,7) 构成的谱系具有唯一的群论嵌入链。

### W2 级猜想（部分证明）

1. **2D 离散 Gauss-Bonnet 定理**：对于闭合的 2 维三角剖分，总曲率 = 2π × 欧拉示性数。

2. **Regge 作用量收敛性猜想**：离散因果格上的 Regge 作用量在精细化极限下收敛于爱因斯坦-希尔伯特作用量。

3. **规范耦合常数统一猜想**：精细结构常数和引力常数由三群谱系的组合性质唯一确定。

### W3 级开放问题

1. **4D 收敛性证明**：将 2D Gauss-Bonnet 定理推广到 4D。

2. **量子引力统一**：将因果格量子化，建立完整的量子引力理论。

3. **宇宙学常数推导**：从因果结构推导出 ΛCDM 模型的所有参数。
