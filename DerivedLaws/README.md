## 一、核心理念

传统物理学从现象出发，归纳出定律；CSQIT 从公理出发，推导出定律。

本文件夹的目标是：
1. **从 W1 层的基本公理**（因果序、编织结构、振幅幺正性等）出发
2. **系统推导出已知的物理、化学定律**
3. **明确每个定律的适用范围**——它是 CSQIT 结构的哪个方面、在什么条件下的体现

**关键认知**：
- 不是所有定律都能在纯 W1 层推导
- 有些需要 W2 层的额外假设（如 `EffectiveFin7Regular`）
- 有些甚至需要 W3 层的物理诠释
- **每个定律都必须标注其依赖层级**

## 二、层级标注规范

每个定律都按以下标准标注其依赖层级。
**重要说明**：文件头的层级指的是**"作为物理定律的推导强度"**，
而不是文件中所有数学定理的强度。
文件内部的纯数学定理（如因果熵单调性、等价关系性质等）本身是 🔵 W1 严格的，
但"这些数学结构对应于某条物理定律"这一断言，通常是 🟢 或 🟡 级别的。

| 标注 | 含义 | 可信程度 |
|------|------|---------|
| 🔵 **W1 严格定理** | 纯从 W1 公理推导，无额外假设 | 最高——经过 Lean 形式化验证 |
| 🟢 **W2 条件性定理** | 核心物理对应只需要 1 个额外假设，推理链严格 | 高——如果假设成立，则定律成立 |
| 🟡 **W2 框架性** | 已有概念框架，但需要多个未证明的跳跃 | 中——方向有启发性，细节待补 |
| 🟠 **W3 诠释** | 数学结构与物理概念的对应关系 | 低——有启发性，但非形式化结论 |
| 🔴 **猜想** | 尚未证明，仅作为研究方向 | 待验证 |

**修正原则**：
- 凡是需要"因果格 = 时空"、"因果熵 = 热力学熵"、"振幅模方 = 概率"这类物理对应假设的，
  至少是 🟢 W2 条件性起步
- 凡是需要多层物理对应跳跃（如两面性→自旋→费米子→泡利原理），
  整体评为 🟡 W2 框架性
- 每个文件内部会具体区分：哪些数学是 🔵 严格的，哪些物理对应是假设

## 五、推导方法论

### 5.1 标准推导模板

每个定律的推导都遵循以下模板：

```lean
/-
定律名称：[物理/化学中的标准名称]
CSQIT 对应：[在 CSQIT 中的数学表述]
依赖层级：[W1/W2/W3]
物理意义：[为什么这对应那个定律]
适用范围：[在 CSQIT 中成立的条件]
-/

theorem law_name [前提条件] :
    [定律的数学表述] := by
  [证明过程]
```

### 5.2 从 CSQIT 到物理定律的"翻译"指南

| CSQIT 概念 | 物理对应 | 备注 |
|-----------|---------|------|
| 因果序 `≤` | 时间先后 | W1 层严格对应 |
| 振幅 `amplitude` | 概率幅 | W1 层严格，模平方=概率需额外假设 |
| 编织操作 `par` | 空间并行 / 叠加 | W1 层结构，物理解释在 W2/W3 |
| 编织操作 `seq` | 时间演化 | W1 层结构 |

| 两面性参数 `θ` | 宇宙组分比例 | W2 层条件性 |
| `EffectiveFin7Regular` | 宇宙的正则性条件 | W2 层假设 |

## 六、与传统物理学的关系

### 6.1 CSQIT 不是"替代"物理学，而是"奠基"物理学

- 传统物理学的定律是**现象学**的——从实验归纳而来
- CSQIT 的定律是**原理性**的——从公理演绎而来
- 当我们说"从 CSQIT 推导出某某定律"时，意思是：
  > 在适当的诠释下，该物理定律的数学结构
  > 是 CSQIT 公理体系的一个推论或一个侧面

### 6.2 推导的"严格程度"递减链

```
W1 严格定理
    ↓ 加假设
W2 条件性定理
    ↓ 加诠释
W3 物理对应
    ↓ 加近似
传统物理定律
```

每一步都在增加内容、降低严格性，但提高物理直观性。

## 七、为什么这件事很重要

1. **概念统一**：看似不相关的物理化学定律，其实都是同一个因果-代数结构的不同侧面
2. **发现新定律**：如果 CSQIT 导出了某个我们还不知道的定律，那就是预言
3. **深化理解**：知道为什么定律是这样的，而不仅仅是知道定律是什么
4. **跨领域连接**：物理和化学的边界在 CSQIT 中消失了——它们都是同一结构的不同表现
