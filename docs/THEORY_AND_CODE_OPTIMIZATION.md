## 二、理论优化思路

### 1. Eckmann-Hilton 死胡同的解决方案

**问题**：在双幺半群中，如果 seq 和 par 处处定义、共享单位元、满足 interchange 律，则必然 `seq = par` 且交换，时空无法分化。

**已验证的出路**（方向 A：带类型的部分运算）：
- ✅ 定义 `Weave L R` 带类型的编织路径（L, R 是因果位点）
- ✅ seq 仅当 `R1 = L2` 时可复合（顺序复合有类型约束）
- ✅ 定义 `ParallelWeave` 结构，par 要求两条路径所有位点两两因果不可比
- ✅ 证明带条件的 interchange 律（SquareIncomparable 条件下成立）
- ✅ Fin 4 因果空间反例：seq 和 par 定义域不同，故 seq≠par

**关键洞察**：运算的部分定义性（类型约束）是避免 Eckmann-Hilton 平凡化的核心。不是"一个集合上的两个幺半群"，而是"2-范畴中不同 hom-集上的复合"。

### 2. 三群谱系的深化

**现状**：
- A₄(12)、A₅(60)、PSL(2,7)(168) 三群谱系统一定义
- totalClosure = lcm(12,60,168)/2 = 420
- 三锁常数（20, 111, 289）数值关系已建立

**待深化方向**：
- 从有限单群表示论直接导出三锁常数（目前是数值验证，非推导）
- A₅ 不可约表示维数 {1,3,3,4,5} 与三锁的对应
- PSL(2,7) 的 168 阶与暗能量 289 的关系（289 = 17² = 生长链第4步平方剩余）
- 三群的"生长"关系：A₄ → A₅ 加入素数 5，A₅ → PSL(2,7) 加入素数 7

### 3. 编织结构的完善

## 五、方法论总结

### 有效的做法

1. **从具体到抽象**：Fin n → 一般类型，避免一开始就追求一般性
2. **反例先行**：先找反例明确边界，再证明定理
3. **定义集中化**：核心定义（如群阶、totalClosure）单点定义，多方引用
4. **层级分明**：W1 严格证明，W2 有效理论，W3 概念探索，各司其职
5. **编译验证驱动**：每次修改后立即编译，及时发现问题

### 需要避免的陷阱

1. **数值验证 ≠ 形式化证明**：`rfl`/`norm_num` 验证的是具体数值，不是一般性
2. **处处定义的运算 → Eckmann-Hilton 平凡化**：部分定义是关键
3. **死代码累积**：及时归档或删除不再维护的文件
4. **重复定义蔓延**：定义漂移导致不一致，必须集中管理
